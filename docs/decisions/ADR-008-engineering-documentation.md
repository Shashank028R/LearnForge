# ADR-008 — Documentation as a Build Requirement

## Status

Accepted

## Decision

Every phase must update engineering documentation alongside implementation.

Required documentation includes:

- architecture;
- dependencies;
- database;
- API;
- security;
- phase report;
- changelog;
- interview guide;
- project context.

## Rationale

The project is intended both as a usable product and as a portfolio project that the owner can confidently explain in interviews.
