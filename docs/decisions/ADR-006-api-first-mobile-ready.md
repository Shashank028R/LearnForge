# ADR-006 — API-First, Mobile-Ready Backend

## Status

Accepted

## Decision

The web client consumes public-style backend APIs for product capabilities. No critical behavior may exist only in browser-local state.

## Rationale

A future mobile client must use the same identity, data, notes, chats, knowledge, and quiz systems.

## Consequences

- slightly more upfront API discipline;
- future mobile development becomes substantially easier.
