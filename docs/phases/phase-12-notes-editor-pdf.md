# Phase 12 — Advanced Notes Editor & PDF Export

## Objective

Complete the note-taking experience and export pipeline.

## Scope

- rich structured editor;
- code highlighting;
- tables;
- diagrams where supported;
- highlights/callouts;
- search/navigation;
- PDF rendering;
- export error handling.

## Acceptance Criteria

Notes remain the canonical structured document and exported PDFs are readable and visually consistent.
