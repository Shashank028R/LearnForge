# Phase 06 — Knowledge Extraction Engine

## Objective

Turn study/chat interactions into validated learning events and concept/knowledge state updates.

## Scope

- learning event extraction;
- subject/topic resolution;
- concept resolution;
- duplicate handling;
- misconception detection;
- knowledge state transitions;
- confidence calculations;
- source attribution.

## Acceptance Criteria

A conversation can produce structured learning events without directly mutating notes from controller code.
