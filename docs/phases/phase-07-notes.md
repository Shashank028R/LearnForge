# Phase 07 — Automatic Notes Engine

## Objective

Generate and safely update structured notes from knowledge events.

## Scope

- note document/block schema;
- initial note generation;
- AI update proposals;
- risk-based update policy;
- note versioning;
- diff/review;
- manual editing basics;
- attribution.

## Acceptance Criteria

New learning can produce structured notes, duplicate content is minimized, user edits are protected, and all material changes are recoverable.
