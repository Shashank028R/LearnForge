# Phase 04 — Chat Infrastructure

## Objective

Build reliable Chat and Message infrastructure independently from advanced AI knowledge processing.

## Scope

- create/list/archive chats;
- subject-linked chats;
- general chats;
- message persistence;
- conversation ordering;
- streaming-ready response design;
- retry-safe message creation;
- chat sidebar/search basics.

## Acceptance Criteria

Chat history is reliable, reload-safe, paginated where appropriate, and subject-linked conversations remain isolated by user ownership.
