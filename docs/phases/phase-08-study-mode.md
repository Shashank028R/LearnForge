# Phase 08 — Study Mode / Strict Teacher

## Objective

Implement the adaptive teaching loop.

## Scope

- Study Session model;
- teacher state;
- teach/ask/evaluate/remediate loop;
- structured answer evaluation;
- misconception capture;
- knowledge updates;
- session summary.

## Acceptance Criteria

The AI does not blindly answer every prompt. It can ask, evaluate, correct, and revisit topics based on evidence.
