# Phase 02 — Professional UI Shell & Design System

## Objective

Create the polished application shell before feature-heavy screens.

## Design Rules

- professional knowledge-management aesthetic;
- no glassmorphism;
- no neon;
- no excessive gradients;
- restrained animation;
- accessible typography and contrast;
- responsive layouts;
- consistent spacing and semantic UI tokens.

## Scope

- app shell;
- sidebar;
- top bar;
- responsive navigation;
- route structure;
- reusable buttons/inputs/dialogs/toasts;
- empty/loading/error states;
- light/dark theme strategy if included by final product design.

## Acceptance Criteria

The shell looks like a serious productivity/study product and not a generic AI landing page.

## Documentation

Update architecture, UI notes in project context, dependency registry, changelog, and phase report.
