# Phase 03 — Subjects, Topics & Knowledge Structure

## Objective

Implement the subject/topic/concept foundation.

## Scope

- subject CRUD;
- topic hierarchy;
- canonical concepts;
- subject navigation;
- basic subject overview;
- user ownership rules.

## AI-Assisted Creation

Automatic subject/topic discovery can be introduced through services, but the data model must not depend on AI being available.

## Acceptance Criteria

A user can create and manage subjects and topics and cannot access another user's data.
