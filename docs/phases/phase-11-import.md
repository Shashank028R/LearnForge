# Phase 11 — Conversation Import System

## Objective

Import external study conversations safely and integrate them into existing or new subject knowledge.

## Scope

- pasted text;
- supported export files;
- normalization;
- subject/topic detection;
- duplicate/conflict analysis;
- merge preview;
- create new chat;
- create new subject.

## Acceptance Criteria

Import never silently destroys existing knowledge and users can choose the destination workflow.
