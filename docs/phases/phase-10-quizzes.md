# Phase 10 — Quiz & Assessment Engine

## Objective

Generate and evaluate quizzes from covered knowledge and feed outcomes back into the Knowledge Engine.

## Scope

- quiz scope selection;
- adaptive mode;
- question generation;
- schema validation;
- objective scoring;
- AI evaluation for open answers;
- attempt history;
- concept-level outcomes.

## Acceptance Criteria

A user can quiz covered topics, receive reliable results, and see knowledge/progress affected by the outcome.
